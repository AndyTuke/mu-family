mu-Tilate factory loops
=======================

Six short drum loops (2 bars of 4/4, 44.1 kHz, 24-bit mono). The tempo is the number at the end of each file name.

Licence: original. Rendered by scripts/make-tilate-factory-loops.py (synthesised, no samples), released as CC0 (public domain).
Credit: Transwarp Development Project.

To use them, copy the .wav files into the Samples folder of your mu-Tilate content folder (Settings shows where it is),
then choose them from a layer's Load button.
