macOS is on hold. Without an Apple code-signing certificate the plugins can't be properly signed and notarized for Mac, so macOS development is paused for the foreseeable future and there are no Mac downloads. If that changes, it'll be announced on the mailing list.

Linux is beta. The Linux builds are new and still being tested, so expect rough edges. Each product above has a Linux download except μ-link, which is Windows only. Questions? Email support@transwarp.me.

All downloads are .zip archives containing the VST3, CLAP (and Standalone where applicable). Unzip and copy the plugin into your system plugin folder. Got a licence key? Open the plugin, choose Enter a key (in About, or from the support message) and paste it in. Trouble installing? Contact support.
